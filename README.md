# 공지민 · 교육 기록

노란색·파란색과 흰색을 중심으로 구성한 유아교사 개인 홈페이지입니다.

사이트: https://kongjimin01.github.io/jimin_portfolio_/

## 구성

- 자기소개와 프로필 사진
- 숭의여자대학교 유아교육과: 2020.03–2023.02, 3년 과정, 학점 4.16/4.5
- 사립유치원 담임교사: 2022.03–현재, 만 4년
- 보육교사 2급 · 유치원 정교사 2급
- 2026년 소식지 18편: 대표 4편의 첫 페이지 미리보기와 전체 목록
- 월안 4편: 2페이지 미리보기
- 태극3반 휴지 프로젝트 활동 기록: 11페이지의 활동 사진 미리보기

모든 자료를 클릭하면 전체 PDF가 새 탭에서 열립니다. 원본 PDF 23개는 docs/pdfs에 포함되어 있으며 수정하지 않았습니다. 자기소개와 작품 설명은 제공된 경력과 자료 내용을 바탕으로 작성한 초안입니다.

## 수정과 게시

본문은 docs/index.html, 디자인은 docs/styles.css에서 수정합니다. 별도의 설치나 빌드 없이 볼 수 있는 정적 홈페이지입니다.

main 브랜치에 푸시하면 GitHub Pages가 docs 폴더를 자동으로 게시합니다.

Google Fonts의 Noto Sans KR을 사용하며, 오프라인에서는 시스템 글꼴로 표시됩니다.
